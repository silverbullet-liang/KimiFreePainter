
# Android 端使用说明

## 安装

1. 从 [Releases](https://github.com/silverbullet-liang/KimiFreePainter/releases) 下载最新 APK
2. 安装（需允许"未知来源"）
3. 打开 App

## 首次登录

1. 进入设置页
2. 点击「登录」条目
3. 在全屏 WebView 中完成 Kimi 登录
4. 检测到 token 后，底部浮出「保存并返回」
5. 点击保存，回到设置页

## 生图

1. 进入生图页
2. 输入提示词
3. 点击「开始创作」
4. 保持 App 在后台（前台 Service 保活）
5. 收到通知后回到 App 查看结果

## 历史

1. 进入历史页
2. 点击任意条目查看详情
3. 长按描述可复制
4. 点击「保存图片」保存到相册
5. 左滑删除条目

## 设置

| 设置项 | 说明 | 默认 |
|---|---|---|
| 记住登录 | 加密保存 token，重启免登录 | 开 |
| 删帖模式 | 只删触发帖 / 不删 / 全删 | 只删触发帖 |
| 删帖延迟 | 全删模式下的延迟 | 30 秒 |
| 轮询间隔 | 拉取作品帖的频率 | 10 秒 |
| 单任务超时 | 超过则标记失败 | 5 分钟 |
| 画师 | 自动识别，可手动重选 | @AI画师 |
| 自动清理 | 历史自动清理周期 | 关 |
| 清空历史 | 手动清空所有历史 | — |

## 常见问题

**Q: 为什么必须保持 App 在后台？**
A: 创作任务需要前台 Service 保活，切到后台可以，但不能杀进程。

**Q: 通知栏常驻通知可以关闭吗？**
A: 不建议。关闭后切后台可能被系统杀，任务会中断。

**Q: Token 保存在哪里？安全吗？**
A: EncryptedSharedPreferences（Android Keystore 加密）。App 沙箱保护，其他 App 无法读取。

**Q: 为什么我的账号提示异常？**
A: 见 [DISCLAIMER.md](../DISCLAIMER.md) 第 3.1 条。账号风险自担。
