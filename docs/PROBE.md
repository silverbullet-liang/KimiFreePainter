- P-05 通过 → 才做「参考图」入口；不通过 → 永久不做

## 已确认的事实（来自客户端逆向文档）

- 成品帖判据：`content.source == MOMENT_SOURCE_AI`
- 机器人评论判据：`type == COMMENT_TYPE_BOT` 且 `aiGenerated == true`
- 机器人身份：`moment.v1.UserService/ListMentionableBots`（`sceneType=MENTIONABLE_SCENE_TYPE_AGENT`）
- 所有社区接口为 Unary RPC，`Content-Type: application/json`
