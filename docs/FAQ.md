
# 常见问题 FAQ

## 关于项目

**Q: 这个项目和 Kimi 官方有关系吗？**
A: 没有。本项目是非官方的第三方客户端，与北京月之暗面科技有限公司无任何隶属、合作、授权或背书关系。

**Q: 为什么叫「免费画师」？**
A: 因为 Kimi 社区的 `@AI画师` 生图功能本身就是平台免费提供给所有登录用户的。本项目只是把它做得更快捷、更美观、更方便。

**Q: 会消耗我的额度吗？**
A: 不会。`@AI画师` 不计费、不计次、不扣 token、不涉及会员。本项目不绕过任何付费机制，因为该功能本身免费。

**Q: 为什么英文文案里 @AI画师 还是中文？**
A: 因为 `@AI画师` 是 Kimi 社区里该 bot 的**唯一名称**，是中文的，不可翻译。英文读者必须原样输入 `@AI画师` 才能触发。翻译成 `@AIArtist` 或 `@AI Painter` 反而会误导。

## 关于登录

**Q: 登录要做什么？**
A: 只有一件事：用 Kimi App 扫一下二维码。两端都在本地生成二维码并向 `auth.kimi.com` 轮询状态，令牌由服务端直接下发，不经过任何中转。没有手填令牌的入口——那对不懂技术的用户既不友好也有泄露风险。

**Q: Android 端登录后为什么不用重登？**
A: Token 使用 EncryptedSharedPreferences 加密持久化。accessToken 过期时自动用 refreshToken 静默续期。

**Q: Web 端的登录状态怎么保持？**
A: 令牌只存本机 localStorage。每 60 秒检查一次 access 是否过期，过期就用 refreshToken 换新；换不上判定掉线，界面立刻反映。

**Q: 二维码扫完没反应？**
A: 先看二维码下的状态文案：卡片显示「已扫码，请在手机上确认」说明扫描成功，只差手机上点确认；一直停在「请用 Kimi App 扫描二维码」说明扫描没被识别，点「刷新二维码」重来；显示「二维码已过期」就直接刷新。

## 关于生图

**Q: 为什么生图要等 1–5 分钟？**
A: `@AI画师` 的生成在 Kimi 服务端完成，本项目只能轮询等待。进度条是时间估算，不是真实进度。

**Q: 为什么有时候识别不到作品帖？**
A: 5 分钟内没识别到时，会走评论区反查兜底。如果仍失败，可能是生成帖被审核删除或服务端异常，标记为失败后可以手动重试。

**Q: 删帖模式选什么好？**
A: 默认「只删触发帖」——主页只留成品，干净且风控友好。全删模式有延迟 30–60 秒的保护，但仍是强风控特征，不建议高频使用。

## 关于安全

**Q: 数据会上传到你们的服务器吗？**
A: 本项目没有服务器。Android 端所有数据仅在本机；Web 端所有数据仅在浏览器本地。

**Q: 会泄露我的 token 吗？**
A: Android 端 token 用 Android Keystore 加密。Web 端默认临时会话模式（内存），开启持久化则明文存 localStorage。请勿在公共电脑开启持久化。

**Q: 为什么提示「账号风险」？**
A: 本项目调用非公开接口，可能与 Kimi 的服务条款存在差异。详见 [DISCLAIMER.md](../DISCLAIMER.md)。账号风险自担。
